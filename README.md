# 🐍 Black Mamba

Black Mamba is a modern Snake Game built with Python and Pygame. 
The game features smooth movement, animated visuals, glowing fruits, sound effects, responsive controls, a high-score system,
and a polished user experience.

---

## 🎮 Features

- Smooth snake movement and turning
- Detailed snake design with animated body scales
- Multiple fruit types
- Glowing fruit effects
- Animated fireflies background
- Background music and sound effects
- Keyboard Controls 
- On-screen touch/mouse controls
- Pause Menu (Resume, New Game, Quit)
- High Score Saving System
- Responsive UI and Window Resizing Support
- Custom Welcome Screen
- Custom Game Over Screen

---

## 📥 Installation

### Method 1: Download Pre-built EXE (Recommended)

1. Open the GitHub repository.
2. Go to the **Releases** section.
3. Download the latest version of:

   `SnakeGameSetup.exe`

4. Run the installer.
5. Follow the installation steps.
6. Launch **Black Mamba** from the Desktop shortcut or Start Menu.

---

## ▶️ How to Play

### Keyboard Controls

| Key / Button | Action |
|-------------|---------|
| ↑ | Move Up |
| ↓ | Move Down |
| ← | Move Left |
| → | Move Right |
| Space | Pause / Resume |
| Enter | Select Pause Menu Option |
| On-Screen Buttons | Control Snake Direction |
| Pause Button | Open Pause Menu |

### Mouse Controls

- Click on the on-screen buttons to control the snake.
- Click the Pause button to open the pause menu.
- Use the mouse to select menu options.

---

## 🎯 Objective

- Eat fruits to gain points.
- Grow the snake as long as possible.
- Avoid hitting walls.
- Avoid colliding with your own body.
- Beat your highest score.

---

## 🏆 High Score

The game automatically saves your highest score and loads it the next time you play.
